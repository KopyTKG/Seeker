# Seeker

Seeker is a discord bot written in Golang with use of DiscordGO.

> [!WARNING]
> This project is not yet finished, please be patient

## References

- [DiscordGO](https://github.com/bwmarrin/discordgo)
- [Cron](https://github.com/robfig/cron)
- [Valkey](https://github.com/valkey-io/valkey-go)
- [GORM](https://gorm.io/)

## Required

- Valkey caching server

## Confing

Config is autogenerated on first startup.

```toml
[Configuration]
  BaseUri = "https://cve.assurestart.co/api"
  ValkeyIP = ""
  Database = ""
  Cron = "*/2 * * * *"
  TimeZone = "Europe/Prague"

[Authentication]
  Token = ""
  Channel = ""
  Guild = ""
  Admins = []
  Roles = []

[Severities]
  CRITICAL = "FF2929"
  HIGH = "F79511"
  MEDUIM = "FAE95C"
  LOW = "C7FFFB"
  NONE = "CCCCCC"

[Logging]
  Logfile = ""
  Loglevel = "DEBUG"

[Cache]
  Expiration = 86400
```

> [!NOTE]
> API limit is per terms, max per request is 10 terms and 100 items.
> Items are dedupped and sorted to be latest.
