# Seeker

Seeker is a discord bot written in Golang with use of DiscordGO.

> [!WARNING]
> This project is not jet finished, please be patient

## References

- [DiscordGO](https://github.com/bwmarrin/discordgo)
- [Cron](https://github.com/robfig/cron)
- [Valkey](https://github.com/valkey-io/valkey-go)

## Required

- Valkey caching server

## Confing

Config is autogenerated on first startup.

```toml
Token = ""
BaseUri = "https://cve.assurestart.co/api"
ValkeyIP = ""

[Severities]
  CRITICAL = "FF2929"
  HIGH = "F79511"
  MEDUIM = "FAE95C"
  LOW = "C7FFFB"
  NONE = "CCCCCC"
```
